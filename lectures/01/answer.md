# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答（要約でよい）：基礎・応用・発展のような一般的な難易度分けだと説明した。修了ラインや推奨ライン、必要なスキルについても述べた。
- 用語集の正しい意味と比べて気づいたこと：正しくは「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」の3つから1つ選べば完了で、原則採点はない。モデルは一般論から、難易度の序列や修了条件を推測していた。
- 表示できたトークン数（入力 / 出力）：今回の6回は入力が各21。出力は Flash Lite が 541 / 782 / 620、Flash が 566 / 638 / 619。

## 宿題

- 取り組んだレベル：基礎
- やったこと：質問「AIE2026の講座の宿題にある『3レベル』とは何ですか？」を固定し、`gemini-3.5-flash-lite` と `gemini-3.5-flash` で各3回実行した。temperature は指定せず既定値。
- 結果：Flash Lite の3回答は、基礎・応用・発展の一般的な分類を説明した。2回目は習熟度・思考の深さ・コードの3パターンを挙げ、回答が特に長かった。Flash の3回答も同様の分類だったが、修了・合格ライン、推奨レベル、RAGや精度目標など、講座資料にない説明を毎回異なる形で加えていた。どちらのモデルも、実際の「基礎・実装・発展」という選択肢の意味は答えられなかった。
- 気づき・疑問：同じモデルでも回答の表現・長さ・例が変わり、モデルを変えると詳しさや推測の内容も変わった。一方、6回答とも講座固有情報を知らないまま、一般論を確かな説明のように補っていた。回答の流暢さだけでは正確さを判断できず、用語集などの根拠との照合が必要。
